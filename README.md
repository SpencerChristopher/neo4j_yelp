# Yelp Graph Analyzer

This project aims to build a Yelp-style recommendation engine using Python and Neo4j. It processes Yelp dataset information to create a graph database for efficient querying and analysis.

## Key Features:
- Data ingestion and transformation from CSV files to Neo4j.
- Graph data modeling for users, businesses, reviews, categories, and locations.
- Integration with Neo4j APOC and Graph Data Science (GDS) libraries.
- Pydantic models for data validation during ETL.
